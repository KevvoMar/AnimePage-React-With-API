# 🎌 Anime Search App (React + Jikan API)

A responsive anime discovery app built with React and powered by the Jikan API.  
Users can search for anime, view detailed information, and explore recommended titles through a clean, modern UI.

This project focuses on API integration, dynamic routing, reusable components, and smooth user experience.

---

## 🚀 Features

- **Live Anime Search**  
  Search for any anime using real API data.

- **Dynamic Anime Details Page**  
  View episodes, score, status, synopsis, and cover art.

- **Recommended Anime**  
  Automatically fetches related anime and displays up to four suggestions.

- **Fallback Recommendation Logic**  
  If an anime has fewer than four recommendations, the app fills the remaining slots with top‑ranked anime.

- **Responsive UI**  
  Fully optimized for desktop and mobile.

- **Smooth Loading States**  
  Prevents UI popping and handles async fetch delays cleanly.
